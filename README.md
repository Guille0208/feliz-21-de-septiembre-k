# Flores Amarillas

Base de la landing page preparada con React, Vite, Tailwind CSS 4, Motion y Lucide React.

## Ejecutar el proyecto

```bash
npm run dev
```

Después abre `http://localhost:5173`.

## Comandos disponibles

- `npm run dev`: inicia el entorno de desarrollo.
- `npm run build`: genera la versión de producción.
- `npm run lint`: revisa el código.
- `npm run preview`: muestra localmente la versión compilada.

## Carpetas preparadas

- `src/components`: componentes reutilizables.
- `public/photos`: fotografías que usa la página.
